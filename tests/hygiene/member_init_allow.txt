# Format: <path> <Class>::<member>  # why

# A member belongs here ONLY when leaving it unwritten is the point. That is nine
# members in this tree, all of them the maths types' storage: each of `Vec2`, `Vec3`,
# `Vec4`, `Quat`, `Mat3` and `Mat4` has a `Qt::Uninitialized` overload whose whole

# setToIdentity). A default member initialiser would zero the storage first and defeat
# the overload — it would cost a write per temporary in the maths inner loops.
#

# with the one-line default member initialiser, never with a row here: the initialiser

# re-verify. A row that stops matching a real member is a FAILURE of this gate, not a
# harmless leftover — delete it.
